# Banana Pi M7 Industrial Control Framework

Это прототип программной платформы для одноплатного компьютера Banana Pi M7. Приложение реализует сбор данных с цифровых и аналоговых измерительных устройств по сети Ethernet, передачу данных на исполнительные устройства, консольный интерфейс оператора и подсистему модульных алгоритмов управления.

## Возможности

- Загрузка описания измерительных и исполнительных устройств из файла `config/devices.cfg`.
- Сервис опроса измерительных устройств с использованием простого TCP-протокола (`READ\n`). Значения масштабируются согласно параметрам `scale` и `offset`.
- Сервис управления исполнительными устройствами с валидацией допустимого диапазона значений и отправкой команды (`WRITE <value>\n`).
- Консольный пользовательский интерфейс для просмотра и редактирования конфигурации, просмотра текущих измерений, ручной записи на исполнительные устройства и создания шаблонов пользовательских алгоритмов.
- Движок алгоритмов, динамически загружающий скомпилированные модули (`.so`) и выполняющий их с указанным интервалом. В репозитории присутствует пример алгоритма `sample_algorithm`.

## Структура проекта

```
include/            Заголовочные файлы
src/                Основная реализация сервисов и консоли
modules/            Каталог алгоритмов (пример и шаблоны)
config/devices.cfg  Конфигурация устройств
```

## Сборка

```
cmake -B build -S .
cmake --build build
```

Исполняемый файл будет доступен по пути `build/tiktak`. Модули алгоритмов размещаются в `build/modules`.

## Запуск

```
./build/tiktak [путь_к_конфигурации]
```

Приложение автоматически загружает модули из каталога `modules` (скомпилированные `.so` файлы). Для Banana Pi M7 сборка может выполняться непосредственно на устройстве или с использованием кросс-компилятора (потребуется корректировка переменных `CMAKE_TOOLCHAIN_FILE`).

## Добавление алгоритмов

1. В консоли приложения выполните команду `create algorithm <имя>`. Будет создан шаблон файла `modules/<имя>/<имя>.cpp`.
2. Реализуйте алгоритм, используя интерфейс `algorithms::AlgorithmModule`.
3. Добавьте модуль в сборку (создайте `CMakeLists.txt` по аналогии с `modules/sample_algorithm`).
4. Пересоберите проект, чтобы получить `.so` файл.

## Формат конфигурации устройств

```
[measurement:<id>]
name=<описание>
channel=analog|digital
ip=<IPv4>
port=<порт>
driver=<драйвер>
scale=<множитель>
offset=<смещение>
poll_interval_ms=<период опроса>

[actuator:<id>]
name=<описание>
channel=analog|digital
ip=<IPv4>
port=<порт>
driver=<драйвер>
min=<минимальное значение>
max=<максимальное значение>
default=<значение по умолчанию>
```

## Протокол обмена

Для демонстрации используется простой текстовый протокол по TCP:

- Сервис опроса отправляет строку `READ\n` и ожидает числовой ответ.
- Сервис управления отправляет `WRITE <value>\n`.

Реализация драйверов устройств может быть адаптирована под конкретные промышленныe протоколы (Modbus/TCP, EtherCAT, OPC UA и др.) за счёт расширения `network::EthernetTransport`.
